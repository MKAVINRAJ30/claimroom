# ⚡ ClaimRoom

> **A real-time "first to claim" live sales room for small sellers.**  
> Built for **Build Something Real: The Serverpod Hackathon** using Serverpod 4, PostgreSQL, and Flutter.

---

## 🎯 The Problem

Small independent sellers in India and globally sell through **Instagram Lives** and **WhatsApp groups**. During drops:
- Buyers comment `"mine"`, `"sold"`, or `"claim"`.
- The seller tries to track claims manually on paper or in spreadsheets.
- **Race conditions**: Multiple buyers claim the same unique item at the same time, leading to double-sales, disappointed customers, and angry DMs.
- **Unpaid / ghost claims**: Buyers claim items but disappear, leaving stock locked while others wanted to buy.

## 💡 The Solution

**ClaimRoom** replaces spreadsheets and chat chaos with a dedicated real-time room:
1. **Seller** creates a live room, adds products, and shares the 5-character join code (e.g. `K9X2P`).
2. **Buyers** join live, watch products update instantly, and tap **CLAIM NOW**.
3. **Atomic Claiming**: Serverpod handles each claim inside a PostgreSQL database transaction with `LockMode.forUpdate`. Even if 50 buyers tap at the exact same millisecond, row-level database locking guarantees **only one claim succeeds**. Double-selling is mathematically impossible.
4. **Hold Timer & Auto-Release**: Winning claims get a **60-second hold**. If the buyer doesn't confirm in time, a Serverpod **Future Call** automatically releases the item back to the room.
5. **Real-Time Streaming**: Serverpod streaming endpoints push live events (`item_claimed`, `item_confirmed`, `item_released`) to all attendees simultaneously.
6. **Order Sheet & WhatsApp Export**: When the sale ends, the seller gets an aggregated order sheet grouped by buyer with a 1-tap **Copy WhatsApp Summary** button ready to send to customers!

---

## 🛠️ How Serverpod 4 is Used

| Feature | Implementation | Why It Matters |
|---|---|---|
| **Database Transactions** | `session.db.transaction((t) => ...)` with `LockMode.forUpdate` | Guarantees atomic claims; prevents double-selling under high concurrency |
| **Future Calls** | `HoldExpiryFutureCall` via `session.serverpod.futureCalls.callWithDelay(...)` | Server-side scheduled task that automatically expires abandoned holds after 60s |
| **Streaming Endpoints** | `client.room.streamRoom(roomId)` via `session.messages.createStream(...)` | Real-time WebSocket event bus pushing instant state updates to all buyers & seller |
| **Shared Client** | `claimroom_client` generated by Serverpod | Type-safe shared models and endpoints between backend and Flutter frontend |
| **Embedded Database** | Serverpod embedded PostgreSQL (`config/development.yaml` & `config/test.yaml`) | Instant setup without requiring Docker or manual database configuration |

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://flutter.dev) (v3.24+ / 3.44+)
- [Dart SDK](https://dart.dev) (v3.5+ / 3.12+)
- [Serverpod CLI](https://serverpod.dev) (`dart pub global activate serverpod_cli`)

### Running the App

1. **Clone the repository:**
   ```bash
   git clone <repo-url>
   cd claimroom
   ```

2. **Start the Serverpod Server & Web App:**
   ```bash
   serverpod start
   ```
   *This starts the Serverpod API server (port 8080), the Insights server (port 8081), applies database migrations to the embedded PostgreSQL instance, and launches the Flutter application.*

3. **Running the Flutter App Separately (Desktop/Mobile/Web):**
   ```bash
   cd claimroom_flutter
   flutter run -d chrome
   ```

## 📱 How to Demo the Flow (2-Minute Demo Script)

1. **Launch the App**:
   - Open two browser windows side by side (Window A = Seller, Window B = Buyer).
2. **Start a Live Sale**:
   - In Window A, click **"⚡ Quick Start Instant Demo"** or create a room ("Friday Thrift Drop").
   - Click **"Open as Seller"**. Notice the 5-character room code (e.g. `K9X2P`).
3. **Join as Buyer**:
   - In Window B, enter the room code and join as `"Priya"`.
4. **Demonstrate Atomic Claim**:
   - Tap **"CLAIM NOW"** on an available item.
   - Notice the instant real-time update in both windows:
     - Seller sees: `HELD BY PRIYA` with live countdown timer!
     - Buyer sees: `HELD FOR YOU (0:59)` with "CONFIRM CLAIM" and "RELEASE" buttons!
5. **Confirm Claim**:
   - Click **"CONFIRM CLAIM"**. Status instantly shifts to **SOLD**.
6. **View Order Sheet**:
   - In the Seller window, tap the **Receipt (Order Sheet)** icon.
   - View total revenue, items sold, and tap **"Copy WhatsApp Summary"**!
